Deploying to WolfCloud

WolfCloud is built for speed. We've removed the friction of Git pushes for a direct Drag-and-Drop workflow.

How to Upload

1. Navigate to 'New Project' from your Dashboard.
2. Select your local file (index.html, styles.css, etc).
3. Drag it directly into the upload zone.
4. Click [DEPLOY].

Once deployed, your files are synced to global S3 buckets and served via our edge proxy.

How to Update

The system detects updates based on Filename Consistency. You don't need to delete your old project to make a change.

Sync Rule: To update a hosted file, drag in a new file with the exact same name.
  • Modify your file locally (e.g., update index.html).
  • Drag the updated file into the project dashboard.
  • System identifies the matching name and overwrites data in the Storage list.
  • Click Deploy to purge the edge cache.

Routing & URLs

Every project is assigned a predictable, professional URL structure.

https://wolfcloud.onrender.com/:user/:repo
https://user.wolfvox.me/:repo

Replace :user with your WolfVox username and :repo with your project name.

https://user.wolfvox.me/profile

This will show your profile which is Public and visible to everyone.

Data Persistence

Unlike the WolfVox Forms platform (which clears data every 24 hours), WolfCloud is designed for permanence.

Secure Storage

All files are stored in persistent S3-compatible buckets. Your site remains online until you manually delete it.
